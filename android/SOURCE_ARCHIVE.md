# Aura Launcher Android v0.1

O projeto completo está no arquivo `launcher-source.tar.xz` (SHA-256 `38e45deaa40485bc20948c5b16abeb16638210db3f203e08c4f2a5b36c178698`).

Extração local a partir da raiz do repositório: `tar -xJf android/launcher-source.tar.xz`. A Action `Aura Launcher Android source and APK` também expande os arquivos para paths navegáveis e tenta compilar um APK de debug.

`android/phone/` e `android/tv/` são os endpoints independentes. A v1 é o pacote base embutido no APK; nunca publique a chave privada de assinatura.
